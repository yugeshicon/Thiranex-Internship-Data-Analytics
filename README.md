# Thiranex Data Analytics Internship

This repository contains the tasks completed during the Data Analytics Internship program.  
The projects focus on data analysis, visualization, predictive analytics, and automation using modern analytical tools and techniques.

---

# Task 1: Sales & Revenue Analysis Dashboard

## Question
Build a dashboard to analyze sales and revenue data.

### Key Features
- Import data from Excel, CSV, or databases
- Visualize KPIs such as total sales, revenue trends, and top-performing products
- Use charts, filters, and slicers for interactive analysis

### Expected Outcome
- Learn data visualization techniques
- Understand KPI tracking
- Generate meaningful business insights

---

# Task 2: Customer Segmentation Project

## Question
Segment customers based on behavior and demographics.

### Key Features
- Perform clustering using Python (scikit-learn) or Power BI
- Analyze purchase patterns and customer preferences
- Visualize customer segments and their characteristics

### Expected Outcome
- Gain experience in customer analytics
- Understand customer segmentation methods
- Create targeted business insights

---

# Task 3: Predictive Analytics Using Historical Data

## Question
Build a predictive model to forecast future trends.

### Key Features
- Use regression or time-series models for prediction
- Clean and preprocess historical datasets
- Evaluate model accuracy and visualize predictions

### Expected Outcome
- Learn predictive modeling techniques
- Understand trend analysis
- Develop data-driven forecasting skills

---

# Task 4: Data Cleaning & Reporting Automation

## Question
Automate data cleaning and reporting workflows.

### Key Features
- Use Python, Excel, or Power BI for automation
- Handle missing values, duplicates, and inconsistent data
- Generate automated reports and visual summaries

### Expected Outcome
- Understand data preprocessing techniques
- Learn workflow automation
- Improve reporting efficiency
